# Deployment readiness

## Status

**Implementation prepared for a configured, single-instance Rutgers pilot deployment. Not yet a live campus service or signed app-store release.**

The operator confirmed there are currently no hosting/email services configured. Production runtime deliberately rejects incomplete setup instead of falling back to a fictional identity. Required values, deployment, recovery, signing and rollout steps are in [deployment.md](deployment.md).

## External gates still open

1. **Hosting and credentials:** create/connect the persistent host, verified SMTP sender, private offsite bucket, support mailbox, and Rutgers moderator account. Review the paid hosting/disk choice before provisioning it.
2. **Real-service staging:** verify a real Rutgers inbox; complete a two-account test on the deployed HTTPS origin; check account export/deletion and moderation delivery; observe a successful offsite backup and perform an actual recovery drill.
3. **Phones and distribution:** connect an Expo project, provide the release API origin, verify package/bundle identifiers, configure the Android maps key and platform signing accounts, and test installed builds on iOS and Android. Foreground location permission, background/resume, revocation and device storage still require actual device checks.
4. **Pilot operations:** review the policy pages, staff the moderation queue, configure uptime/error/backup/disk monitoring, and keep the initial rollout small enough for the documented single-instance limits.

These are real remaining requirements, not automated checks claimed as completed. No production service, paid resource or app-store submission has been created.

## Current limits

Single-instance SQLite with a persistent disk; no serverless/ephemeral deployment or shared replicas. Bounded discovery/event/chat responses and polling are designed for the initial campus pilot, not an unrestricted Rutgers-wide rollout. School email proves mailbox control, not identity/current enrollment. Illustrated avatar choices are available; photo uploads, push notifications and enrollment integration remain outside this version.
